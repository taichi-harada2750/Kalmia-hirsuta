# Project: Kalmia hirsuta

## 概要
Kalmia hirsuta は、Unity を用いて構築される未来的OS型UIのプロトタイプであり、ユーザーの身体動作、特に手の動きのみでUIを操作できる非接触型のユーザーインターフェースである。プロジェクト名は、従来のインタラクション実験 "Kalmia" から派生し、より応答性と視覚演出に優れた"浮遊型OS UI"として設計される。

## コンセプト
- 空中に浮かぶ小さな「UI召喚ボタン」を手で握ると、リング型UIが放射状に展開される
- ユーザーの手の動きをカーソルとして扱い、UI項目を指向選択
- 握る動作で選択決定し、アプリが起動
- サンプルアプリとして「写真アプリ」「インターネットブラウザ」などを内包
- Unity 内部に Web ブラウザを統合し、手の動きによるスクロールや操作を可能に

## 機能一覧（プロトタイプ段階）
### UI召喚
- 空中に常駐する半透明のボタン（未来感のあるエフェクト付き）
- ボタンに手を近づけて「握る」とリングUIが出現

### リングUI構造
- 6〜8個のアイコンが円形に配置（各アプリのエントリ）
- 選択中の項目はスケール拡大や発光でフィードバック
- 手の方向ベクトルから選択インデックスを計算
- 握る動作で選択決定 → アプリ起動

### アプリ例
#### 写真アプリ
- 横スクロール型のギャラリービュー
- 手の動きでページ送りやスワイプを再現

#### Webブラウザ
- Unity内でWebViewを使った簡易ブラウザ
- 手の上下動でスクロール可能
- 将来的にページ入力・戻るなども検討

## 使用技術
- Unity 2022.3系
- Mediapipe（手のトラッキングと握り動作の判定）
- World Space Canvas + 自作UIレイアウト（リング状配置）
- DOTween / Animator を使ったUI演出
- WebView for Unity またはCEF/Edge WebView2
